# 接口文档

## 一、自动生成

### 1. SpringDoc OpenAPI

#### 1.1 引入依赖

**引入Maven依赖**

```xml
// Spring Boot 3.x 版本
<dependency>
    <groupId>org.springdoc</groupId>
    <artifactId>springdoc-openapi-starter-webmvc-ui</artifactId>
    <version>2.5.0</version>
</dependency>

// Spring Boot 2.x 版本
<dependency>
    <groupId>org.springdoc</groupId>
    <artifactId>springdoc-openapi-ui</artifactId>
    <version>1.7.0</version>
</dependency>
```



#### 1.2 基础配置

有两种配置方式，推荐使用**配置类**自定义文档信息。

1. 创建 Swagger 配置类，自定义文档标题、版本、描述等元信息：

```java
import io.swagger.v3.oas.models.OpenAPI;
import io.swagger.v3.oas.models.info.Info;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class SwaggerConfig {

    @Bean
    public OpenAPI customOpenAPI() {
        return new OpenAPI()
                .info(new Info()
                        .title("项目接口文档")
                        .version("1.0.0")
                        .description("基于 SpringDoc OpenAPI 自动生成的接口文档，包含用户、订单等模块"));
    }
}
```



2. 在 application.yml 中配置基础信息：

```yaml
springdoc:
  api-docs:
    path: /v3/api-docs  # 接口JSON文档地址，默认就是这个
  swagger-ui:
    path: /swagger-ui.html  # 页面访问路径，可自定义
    enabled: true  # 是否开启swagger页面
```



#### 1.3 常用注解说明

| 注解           | 作用位置        | 功能说明                                 |
| -------------- | --------------- | ---------------------------------------- |
| `@Tag`         | Controller 类上 | 对接口分组，描述该类接口的整体功能       |
| `@Operation`   | 接口方法上      | 描述单个接口的作用、详细说明             |
| `@Parameter`   | 方法参数上      | 描述单个请求参数的含义、是否必填、示例值 |
| `@RequestBody` | 请求体参数      | 配合实体类使用，自动解析字段             |
| `@ApiResponse` | 方法上          | 描述不同响应状态码的含义                 |
| `@Schema`      | 实体类 / 字段上 | 描述实体类和字段的含义、示例值           |



接口示例（Controller）

```java
import io.swagger.v3.oas.annotations.Operation;
import io.swagger.v3.oas.annotations.Parameter;
import io.swagger.v3.oas.annotations.tags.Tag;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/user")
@Tag(name = "用户管理", description = "用户信息的增删改查接口")
public class UserController {

    @GetMapping("/{id}")
    @Operation(summary = "根据ID查询用户", description = "传入用户ID，返回对应用户的详细信息")
    public User getUserById(
            @Parameter(description = "用户唯一ID", required = true, example = "1001")
            @PathVariable Long id) {
        return new User(id, "张三", 20);
    }

    @PostMapping
    @Operation(summary = "新增用户", description = "传入用户实体信息，创建新用户")
    public String addUser(@RequestBody User user) {
        return "新增成功，用户ID：" + user.getId();
    }
}
```



实体类示例

```java
import io.swagger.v3.oas.annotations.media.Schema;
import lombok.Data;

@Data
@Schema(description = "用户实体类")
public class User {

    @Schema(description = "用户ID", example = "1001", requiredMode = Schema.RequiredMode.REQUIRED)
    private Long id;

    @Schema(description = "用户名", example = "张三")
    private String name;

    @Schema(description = "用户年龄", example = "20")
    private Integer age;
}
```





#### 1.4 启动访问

启动 Spring Boot 项目后，访问以下地址：

- **可视化文档页面**：`http://localhost:端口号/swagger-ui/index.html`
- **原始 JSON 文档**：`http://localhost:端口号/v3/api-docs`

打开页面后可以看到所有接口分组、参数说明、响应示例，还可以直接在线调试接口。



#### 1.5 常用配置

##### 1.5.1  接口分组（多模块文档）

如果项目分为多个模块（如管理端、用户端），可以配置多个分组：

```java
import org.springdoc.core.models.GroupedOpenApi;
import org.springframework.context.annotation.Bean;

@Bean
public GroupedOpenApi adminApi() {
    return GroupedOpenApi.builder()
            .group("管理端接口")
            .pathsToMatch("/admin/**")  // 匹配的接口路径
            .build();
}

@Bean
public GroupedOpenApi userApi() {
    return GroupedOpenApi.builder()
            .group("用户端接口")
            .pathsToMatch("/user/**", "/public/**")
            .build();
}
```



##### 1.5.2 全局请求头（如 Token 认证）

配置全局 JWT 令牌，所有接口统一携带认证头：

```java
import io.swagger.v3.oas.models.Components;
import io.swagger.v3.oas.models.OpenAPI;
import io.swagger.v3.oas.models.security.SecurityRequirement;
import io.swagger.v3.oas.models.security.SecurityScheme;

@Bean
public OpenAPI customOpenAPI() {
    final String securitySchemeName = "bearerAuth";
    return new OpenAPI()
            .info(new Info().title("接口文档").version("1.0.0"))
            // 全局添加认证项
            .addSecurityItem(new SecurityRequirement().addList(securitySchemeName))
            .components(new Components()
                    .addSecuritySchemes(securitySchemeName,
                            new SecurityScheme()
                                    .type(SecurityScheme.Type.HTTP)
                                    .scheme("bearer")
                                    .bearerFormat("JWT")
                                    .description("请输入 JWT 令牌，格式：Bearer token值")
                    ));
}
```



##### 1.5.3 生产环境关闭 Swagger

为了安全，生产环境通常关闭接口文档，在 `application-prod.yml` 中配置：

```yaml
springdoc:
  api-docs:
    enabled: false  # 关闭接口文档JSON
  swagger-ui:
    enabled: false  # 关闭swagger页面
```



##### 1.5.4 放行拦截器 / Security

如果项目有拦截器或 Spring Security，需要放行以下路径：

```
/swagger-ui/**
/v3/api-docs/**
/swagger-resources/**
/webjars/**
```
